# TirsHand 🤾

Appli EPS (handball, Première) : pendant le match, l'équipe note chaque tir (zone, type, résultat). À la fin, elle voit sa **carte de tirs** et écrit son **projet tactique** pour la rencontre suivante.

- Fonctionne hors connexion une fois ouverte (PWA).
- Données stockées uniquement sur l'appareil, export .xlsx pour le professeur (Mes Apps EPS).
- Vidéo différée sans enregistrement.
